EarnBangla starter demo
=======================

This is a static front-end demo only. It does not collect personal data, verify real tasks,
create accounts, or pay money. Points are illustrative only.

Publish with GitHub Pages:
1. Create a public repository named earnbangla.
2. Upload index.html to the repository root.
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site and open the URL shown there.

Do not ask users to deposit money. Before any real rewards or payments, build and test a secure
backend, task verification, privacy policy, terms, abuse prevention, and a lawful payment process.
